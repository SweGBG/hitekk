# HiTekk — v2 "Signal & krets"

Next.js 16 + React 19 + TypeScript. Ren CSS (inga animationsbibliotek, ingen Tailwind).

```bash
npm install
npm run dev
```

- Texter SV/EN: `src/lib/i18n.ts`
- Produkter: `src/lib/products.ts`
- Emblemet (hörlurar + kretskort) är SVG: `src/components/Emblem.tsx`
- Varukorgen är demo — kassan är inte kopplad.
